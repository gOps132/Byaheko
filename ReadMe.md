## Getting Started

### Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

### Run it

```sh
dotnet restore
dotnet build
dotnet run
```

Then open the URL shown in the terminal (typically `http://localhost:5000`).
